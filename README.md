# Конфиги Mac

Личные настройки Fish, Bash, Zsh, Ghostty, Zed, GitHub CLI, Karabiner, OpenCode,
qBittorrent, Starship и скрипт распределения приложений по рабочим столам.
Тема **Midnight MacBook** в Zed служит источником цветов для Ghostty.
Команда `ls` напрямую запускает установленный через Homebrew пакет `nls`.

## Содержимое

- `home/` — 39 рабочих файлов настроек и скриптов с исходными путями относительно домашней папки.
- `snapshots/` — отдельные настройки и списки расширений Zen, Raycast и Zed.
- `Brewfile` — установленный набор приложений и утилит; при чистке пакеты не менялись.
- `scripts/sync.py` — повторный сбор конфигов по явному списку.
- `scripts/check_secrets.py` — проверка снимка и подготовленных к коммиту файлов.
- `scripts/restore.py` — восстановление рабочих конфигов с резервной копией существующих файлов.

История, cookies, пароли, токены, учётные записи, базы данных, кэши,
`node_modules`, скачанные расширения и резервные копии в репозиторий не входят.
Снимок Raycast содержит доступные обычные настройки внешнего вида и список
расширений; авторизация, чаты и данные расширений остаются локально.
Снимок Zen содержит выбранные постоянные настройки, сочетания клавиш, CSS и
список расширений. Он не содержит полного браузерного профиля.

## Обновить репозиторий

```sh
cd ~/dotfiles
/usr/bin/python3 scripts/sync.py
/usr/bin/python3 scripts/check_secrets.py
git add home snapshots managed-files.json
git commit -m "Update device configuration"
git push
```

После нового клонирования включить проверку перед коммитом:

```sh
git config core.hooksPath .githooks
```

Проверка покрывает известные форматы токенов и чувствительные ключи; добавляй
новые файлы настроек в список `PATTERNS`, а не всю домашнюю папку.

## Восстановить конфиги

Просмотр списка файлов:

```sh
/usr/bin/python3 scripts/restore.py --dry-run
```

Восстановление:

```sh
/usr/bin/python3 scripts/restore.py
```

Прежние файлы сохраняются в `~/config-backups/<дата>_before-dotfiles-restore`.
Настройки qBittorrent объединяются с существующими; локальные пароли и cookies
сохраняются. После восстановления открой новую вкладку терминала, перезагрузи
конфиг Ghostty через **⌘⇧,** и при необходимости перезапусти Zed.

Zen/Raycast снимки восстанавливаются отдельно средствами приложений. При
переносе сочетаний клавиш Zen используй текущий профиль, указанный в
`~/.config/zen/installs.ini`, после закрытия браузера. Профили не переносились.

## Автоматические переходы в папки

Введи `!` перед именем папки и нажми Space или Enter: Fish раскроет его в `cd` с полным
путём от домашней папки. Например, `!sem5` превратится в `cd ~/Documents/sem5`.
Enter выполнит переход, Space позволит сначала увидеть и отредактировать команду.

Поиск выполняется при раскрытии сокращения по всей домашней папке, поэтому
новые и переименованные папки доступны сразу, в том числе созданные в Finder
и Zed. Отдельные строки `abbr` для них не сохраняются и не требуют коммитов.

Обычные команды, функции Fish и ручные сокращения имеют приоритет.
При нескольких папках с одинаковым именем или отсутствии папки раскрывается
команда с английским сообщением об ошибке. Сообщение появляется после Enter,
не смешиваясь с редактируемой строкой. Для совпадающих имён используй полный
путь или задай ручное сокращение. Без `!` автоматического перехода нет.

Исключаются скрытые папки, `Library`, `Applications`, `config-backups`,
`node_modules`, `target`, `build`, `dist`, `vendor`, `venv`, `__pycache__`,
`Pods`, `DerivedData` и пакеты приложений/медиатек. Символические ссылки не обходятся.
Автоматическое имя должно состоять из букв, цифр, `_`, `-` и точек и начинаться
с буквы, цифры или `_`. Имена с пробелами могут иметь ручные сокращения.

Настройка: `conf.d/30-auto-directories.fish`; функция: `functions/__auto_directory.fish`.
Для изменения области поиска можно задать переменную `auto_directory_root`.
Существующие сокращения из `config.fish` сохранены.

## Bash

`home/.bashrc` — интерактивные настройки Bash; `home/.bash_profile` загружает
`~/.profile` и `~/.bashrc` для login-сессий. Для интерактивной работы используется
Homebrew Bash 5; системный `/bin/bash` остаётся доступен. Fish остаётся основной
оболочкой; команда `bash` в Fish запускает `/opt/homebrew/bin/bash`.

- Starship использует ту же тему, что и Fish: путь, Git и время долгих команд.
  В Bash перед путём видна жирная голубая метка `bash` без скобок; в Fish метки нет.
- `↑` / `↓` ищут историю по началу введённой команды, `Ctrl+R` — по тексту.
- Серые подсказки продолжения команды из истории и дополнений предоставляет ble.sh.
  `Tab` принимает видимую подсказку, иначе дополняет команду; `Shift+Tab` открывает дополнение.
- История дописывается в `~/.bash_history` и подхватывается между вкладками
  при следующем приглашении. Повторные соседние команды и строки с начальным
  пробелом не сохраняются.
- `ls` запускает обычный `nls`; `ll` — подробный список, `la` — со скрытыми файлами.
- `z имя` переходит в знакомую папку через Zoxide; `mkcd путь` создаёт папку и входит в неё.
- `docs`, `config`, `dotfiles`, `work`, `rust`, `net`, `..`, `...` — переходы в папки.
- `zed` без аргументов открывает текущую папку; с аргументами передаёт их редактору.

Настройки применяются только к Bash. Настройки ble.sh хранятся в `home/.blerc`;
сам пакет установлен единственной копией в `~/.local/share/blesh` и в Git не входит.
При отсутствии ble.sh или запуске системного Bash используется обычный Readline.

Установка на новом Mac после восстановления конфигов:

```sh
brew install bash
bash ~/dotfiles/scripts/install_blesh.sh
```

Starship, Zoxide и ble.sh инициализируются по одному разу; повторное чтение
`.bashrc` не добавляет ещё одну копию обработчиков.
Функция Fish для переходов с `!` в Bash не подключается: здесь используется `z`.

## Общие цвета Fish и Bash

Палитра подсветки вводимых команд хранится в `home/.config/shell/colors.conf`
(рабочий файл — `~/.config/shell/colors.conf`). Здесь задаются цвета команд,
параметров, путей, подсказок, ошибок, комментариев, ключевых слов, опций,
кавычек, операторов и escape-последовательностей. Значения — RGB из шести
шестнадцатеричных цифр без `#`.

Fish читает палитру из `conf.d/40-theme.fish`, Bash/ble.sh — из `.blerc`.
В этих файлах остаются только соответствия цветов и особенности оболочек.
После изменения рабочего файла новая сессия автоматически подхватит цвета;
для уже открытого Fish выполни `source ~/.config/fish/conf.d/40-theme.fish`,
для Bash с ble.sh — `source ~/.blerc`. Повторно читать `.bashrc` для цветов не нужно.
Палитра — файл данных: содержимое не выполняется как команды.

## Переключение рабочих столов через Karabiner

Cmd+1…5 запускают `~/.local/bin/desktop-switch`, который отправляет Dock жест
переключения обычных рабочих столов. Прямой вызов изменения Space в WindowServer
не используется: он нарушал обновление строки меню. Ctrl+1…5 для этого не требуются; системные сочетания остаются
отключёнными. Другие правила Karabiner не меняются. Cmd с дополнительными
модификаторами (например, Shift) не перехватывается этим правилом.

Помощник использует ядро InstantSpaceSwitcher с закреплённым коммитом и рассчитан
на один активный экран. Пакет приложения не устанавливается. Исходник оболочки
и скрипт сборки в Git, программа и MIT-лицензия зависимости — только локально.
Для отправки жестов требуется разрешение Accessibility. После обновления macOS
совместимость следует проверить. Сборка после восстановления:

```sh
bash ~/dotfiles/scripts/install_desktop_switch.sh
```

## Темы и рабочие столы

Меняй палитру в `~/.config/zed/themes/midnight-macbook.json`, затем выполняй
`theme-sync` и **⌘⇧,** в Ghostty. Оформление таблицы `ls` задаёт сам `nls`;
ANSI-цвета отображаются через текущую палитру Ghostty.

Исходник Desktop Assignments хранится в `home/.config/desktop-assignments-sync.swift`.
Сборка после восстановления:

```sh
mkdir -p ~/.local/bin
swiftc -O ~/.config/desktop-assignments-sync.swift -o ~/.local/bin/desktop-assignments-sync
```

LaunchAgent-файлы используют `__HOME__`, который заменяет скрипт восстановления.
Скрипт не загружает агенты автоматически и не меняет распределение рабочих
столов. Подробности — в `home/.config/desktop-assignments.README.md`.

## Проверки

```sh
/usr/bin/python3 scripts/check_secrets.py
/bin/bash -n home/.bashrc home/.bash_profile home/.blerc scripts/install_blesh.sh
fish -n home/.config/fish/config.fish home/.config/fish/conf.d/*.fish home/.config/fish/functions/*.fish
```

Проверка ищет известные форматы токенов и чувствительные ключи в конфигурации.

Результаты чистки перечислены в `CLEANUP.md`.
