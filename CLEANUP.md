# Что исправлено

- `Ctrl+R` в Fish вызывал отсутствующую `_fish_search_history`; теперь используется встроенный `history-pager`.
- `tls.fish` содержал `tmux kill-server` вне функции, способный завершить все сессии при загрузке файла. Удалён устаревший файл: tmux не установлен.
- Удалён неиспользуемый `fish_prompt.fish`, дублирующий Starship.
- Аббревиатура `config` теперь выполняет `cd ~/.config`.
- Путь `js&ts` в аббревиатуре `ts` корректно заключён в кавычки.
- Аббревиатуры и интерактивные настройки не загружаются в неинтерактивном Fish.
- Starship/Zoxide и Rust environment загружаются с проверкой наличия.
- Команда `zed` открывает текущую папку без аргументов и передаёт указанные пути без добавления лишней папки.
- Функции `ls` и `zed` вынесены в стандартные автозагружаемые файлы Fish.
- Путь `~/.npm-global/bin` записан в обычный конфиг, поэтому не зависит от локального `fish_variables`.
- Чтение и проверка общей палитры вынесены в `theme_utils.py`.
- По просьбе пользователя удалён Python-скрипт оформления `nls_table.py` и его тесты; `ls` напрямую вызывает установленный пакет `nls`.
- Генератор Ghostty использует отдельный временный файл для атомарной записи и не переписывает неизменившуюся тему.
- Удалён пустой дублирующий `opencode.jsonc`; настройки Figma MCP сохранены в `opencode.json`.
- Удалены устаревшие `.bak`, `before-ghostty-sync`, старый снимок Spaces и `zen/reset-backup-20260721`.
- Добавлены автоматические сокращения с префиксом `!` для уникальных имён папок по всей домашней папке с исключением служебных данных. Обычные команды и ручные сокращения сохраняют приоритет.

Резервная копия до изменений:
`~/config-backups/2026-10-12_15-31-34_before-cleanup`.

Цвета, текущая тема, назначения рабочих столов, Karabiner-сочетания, история,
